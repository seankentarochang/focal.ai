# @focal-ai/web

The focal.ai website and API — Next.js 16 App Router. Landing and onboarding,
chat, profile/activity/settings, the `/try` playground, the page routes the
extension talks to, and the hosted MCP endpoint.

See the [root README](../../README.md) for setup, environment variables and
test commands; [AGENTS.md](./AGENTS.md) for the conventions this directory
follows (notably: check `node_modules/next/dist/docs` before writing Next.js
code — this version differs from what you may know).
